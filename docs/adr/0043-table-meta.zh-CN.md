# 0043 — 表元信息住在最高的固定面上

> **语言：** [English](0043-table-meta.md)（主） · [中文](0043-table-meta.zh-CN.md)

**状态：** Accepted（2026-10-28）。随 `okm-core/src/model/meta.rs`、
`Collection::{meta, ensure_layout, set_meta}`、`okm-core/tests/meta_test.rs` 一并落地。
动态侧随后走同一套 helper 补齐（2026-10-30：`DynamicCollection::{meta, ensure_layout,
set_meta}`，外加 Python 绑定的 `Collection.ensure_layout`），所以表由哪一侧声明都会盖章。
**日期：** 2026-10-28

## 背景

payload 带一个版本字节（ADR-0042），而这个字节只回答一个问题：这一行是不是**我这个形状**写的？
它一次回答一行，在读者碰到的第一行回答，且对 store 里的每张表分别回答。还没人读过的 store，
和一个全新的 store 在字节上无法区分。

它周围本来有两件既成事实。

- Aura 不得不在自己那一层发明同一道检查：在保留的 ns 里放一行原始标记，首 boot 种子、此后每
  boot 校验，于是重编号变成 boot error 而不是静默解码（那边 ADR-0040 的 Update）。这等于每个
  上层产品重新实现一次 okm 自己就知道的事实——它的字节是按哪个形状写的。
- 固定面带在顶端只剩一个号：0x0F，下面是空闲的 0x0B–0x0E。把**最高**的号留作「以后再说」，
  等于把边界预留给一张也许永不出现的面，而新增的单张面本来就该落在下面的空闲带里。

## 裁决

**1. 0x0F 是表元信息面。** 地址 `[partition?][ns][0x0F]`，无尾缀——面级单例，形态与词汇表游标
`[ns][0x02]` 相同。每张表一条，就在这张表自己的 ns 里。

**2. 取最高面，是故意的。** `slot <= 0x0F` 是单字节／两字节的定界判据；元信息坐在**边界上**，
而不是塞进空闲带，于是空闲带保持连续（0x0B–0x0E），后来新增的固定面永远挤不掉它的地址。

**3. 值是名字 → 字节的映射，不是结构体。** wire：`[count u16 BE]`，随后每项
`[name_len varint][名字 UTF-8][value_len varint][值字节]`，项按名字排序，长度用全库同一套 TLV
varint 编码。

- `version` 是运行时写的唯一名字；它的值是一字节，与 payload 头里那个数字相同
  （`Document::LAYOUT_VERSION`）。
- 名字内联是故意的：给一张表盖戳**不该**碰字段名词汇表（0x02/0x03）。否则一次探测会变成一次
  写，而 store 的自我描述会依赖一张它可能根本没有的字典。
- 加第二个名字不需要任何布局决定——这就是映射形态的全部意义。值在这里是不透明字节，含义归
  写下这个名字的人。

**4. 写运行时名字的动词只有一个：`ensure_layout`。** 缺席 → 种子化 `version = 本构建的`；
相同 → 返回该行（连同别处写的名字）；不同，或该行根本没写 version → `Error::LayoutMismatch
{ stored, current }`。调用点是挂载／boot，每张表一次。`Collection::new` 保持零 I/O、仍返回
`Self`——这正是它做成动词、而不是构造期工作的原因。

**5. 调用方用 `set_meta` 记录自己的名字，** 运行时随后重新盖上 `version`。形状戳记因此无法被
调用方改掉，这是有意的。

**6. 它是**检测**装置，永远不是兼容承诺（ADR-0042）。** 挂载时的一次点读，把「这个 store 是按
别的形状写的」变成点名两个数字的拒绝，而不是读到第一行才解码失败。元信息行不被任何读取路径
穿透，什么也不迁移，也不会因为它让任何旧形状变得可读。

## 后果

- **挂载时每张表一次点读；写路径零成本，每一行零成本。** 这个动词的调用位置，本来就是应用声明
  「我要接上这个 store」的地方。
- **它是 ns 里的又一个非行条目。** `scan_keys`、`scan_documents_raw` 与导出按 slot 过滤，所以
  0x0F 要像 0x01/0x02… 那样被跳过；`meta_test.rs` 锁住行扫描不会把它当行返回。
- **它不进导出与快照。** 这一行描述的是**写入方**的形状；导入方给自己的表盖自己的戳。导出是行，
  不是自我描述。
- **没有元信息行的旧 store 和全新 store 是同一份字节。** 缺席即种子化，等于给「那里现有的一切」
  盖章，这是被接受的（ADR-0042 已定：旧 store 丢弃而不是迁移），也正是逐行 payload 版本字节继续
  保留的原因——它是第二道防线，每次解码都查。
- **ns ↔ 形状是声明期的 1:1，没有任何强制。** 两个行类型共用一个 ns，现在也会在 `version` 上
  意见不一，`ensure_layout` 会拒绝第二个——在挂载时。它不是写路径守卫：那会让每次 put 多一次
  点读，而共用 ns 是声明错误，不是运行期状况。
- **最高的固定面用掉了。** 下一个单张面种类领 0x0B；0x0F 要想改派，除非连宽度定界判据一起动。
