# 0041 — 图的索引带着两端

> **语言：** [English](0041-graph-faces-carry-both-endpoints.md)（主） · [中文](0041-graph-faces-carry-both-endpoints.zh-CN.md)

**状态：** Accepted 并**已落地**（2026-10-27）。slot 重排、没有空隙，并为更早写下的 store
加了 `Graph::reindex`。
**日期：** 2026-10-27

## 背景

边集合由五个固定面服务：

```text
0x06  谓词索引     [predicate][edge_id]
0x07  出边         [src][edge_id]
0x08  入边         [dst][edge_id]
0x09  谓词+出      [predicate][src][edge_id]
0x0A  谓词+入      [predicate][dst][edge_id]
```

每一面都只点名**一端**，所以「这一对」不可寻址。「这条断言已经在图里了吗」——写之前要问、
一段材料被重读时每次都问——只能靠扫源节点在该谓词下的全部出度、再在内存里过滤目标来回答。
在 hub 上（member 节点、task 节点），这是这个 store 里最热也最差的读形状。

同时还有两件事成立：`0x06` 是一份**反规范化**的副本——`[predicate][edge_id]` 恰好等于 `0x09`
的 `[predicate]` 前缀扫描所得，连 id 的位置都一样；而向量索引快照坐在 `0x0B`，一旦重排这些
面，`0x0A` 之后就会留一个洞。

## 裁决

**1. 每一面都带着两端，按遍历方向排。**

```text
0x06  出边         [src][dst][edge_id]
0x07  入边         [dst][src][edge_id]
0x08  谓词+出      [predicate][src][dst][edge_id]
0x09  谓词+入      [predicate][dst][src][edge_id]
```

邻接没有丢，因为被遍历的那一端仍然领衔；成对信息是**附加**的。`(src, dst)` 在 0x06 上可寻址，
`(predicate, src, dst)` 在 0x08 上可寻址——后者**就是**断言同一性，一次 seek。

**2. 谓词索引退役。** 用 0x08 的裸 `[predicate]` 前缀扫，得到的集合与 0x06 相同。这是前缀扫，
不是求交集：用「谓词的边」和「节点的边」求交去推「P 的全部边」，等于把索引本来要省掉的那件事
又做一遍，而 `edges_of_predicate` 是一条真查询（`MATCH ()-[r:P]->()`），不是顺手补的方便。

代价是**字节**而不是条目数：每个后缀现在带两个端点，旧面只带 id。少一面也意味着每次
`link`/`unlink` 少一个 put、少一个 del。

**3. 后缀规则跟着前缀走。** 前缀只消费一个节点时，条目是 `另一个端点 + edge_id`，id 是末尾
八个字节——`NodeRef` 自定界，不可能和它混淆。前缀消费了一对（或一个谓词加一对）时，后缀
**就是** id，于是定宽约定恰好留在它承重的地方。

**4. 没有「边 → 两端」这一面，这是刻意的。** 旧布局缺的是**读**，不是索引：边的主行自己就带着
两端（`get_edge` 第一件事就是解出 `src` 和 `dst`，`check_members` 就是核对两者都属于这张图）。
`[edge][head][tail]` 这样的面会把行里的数据再存一遍，而且键序会毁掉邻接——edge id 领衔时
没法按 head 扫。这里欠的是一个**动词**（`edge(id).src/.dst`），不是一张面。

**5. slot 压实，不留空隙。** 图占 0x06–0x09，向量索引快照搬到 0x0A。快照是可丢的缓存，
搬它只花重建时间；旧号下的陈旧 blob 也不会被误认成新的，因为快照头部的 magic 与版本号在
解码任何内容之前就被核对。

**6. 既有的 store 是重建索引，不是照读。** 键变了，**号也变了**：退役的谓词索引恰好落在现在
出边的位置上，旧构建写下的条目会被读成它并不是的东西。所以清空是**必须**而不是可选，也所以
它是图上的一个方法（`reindex`），而不是迁移文档里的一句嘱咐：它扫这四个面的前缀、删掉，再从
主表逐条重新派生。主表——唯一不可重建的东西——从头到尾不碰。

## 后果

- **断言同一性是一次 seek**（`typed_out_to`），与源节点的出度无关。k10r 的查重因此变成精确
  查找；在那之前，每一次写都要付一次扫描加过滤。
- **重读是安全的。** 读到重叠跨度的分析趟会把同一批事实再写一遍，而它们落在已经站着的那条
  边上。
- **一次 `link` 写四条面条目，不是五条**；`unlink` 删四条。
- **`edges_of_predicate` 付的是字节。** 条目数一样，键更长：谓词扫描每跳过一条都要读两个端点。
- **从此有两条后缀规则，混淆的后果是「失败关闭」。** 期待裸 id 的读者在单节点扫描里遇到更长
  的后缀，得到的是空而不是垃圾——与定宽解码器一贯的失败方向相同，也正是「成对的助手」与
  「普通的助手」要分成两个函数的原因。
- **`reindex` 是一条没有时钟、也没有增量形态的写路径。** 它是给「还没大到需要更聪明办法」的
  store 准备的一次性升级；真大到需要的那天，要的是 schema 版本加后台遍历，而现在还没有人需要。
